all-bot 개인정보 처리방침

시행일: 2026년 10월 14일

1. 적용 범위 및 운영자

이 방침은 운영자 유이린이 운영하고 이 방침에 연결한 Discord 봇에 적용됩니다. 봇별 기능과 실제 처리 항목은 다를 수 있습니다. 아래 내용은 현재 운영 중인 기능을 기준으로 한 공통 안내이며, 특정 봇이 별도의 기능이나 외부 서비스를 사용하는 경우 해당 봇의 추가 안내를 함께 확인해 주세요.

개인정보 관련 문의: hipolewlr@naver.com / 운영자 GitHub 프로필

2. 처리하는 정보와 목적

  • Discord 식별자 및 서버 설정: 서버·채널별 기능 설정과 응답 대상 확인을 위해 서버 ID, 채널 ID, 사용자 ID를 처리합니다.
  • 기능 사용 기록: 호감도 기능을 제공하기 위해 서버 ID, 사용자 ID 및 점수를 저장할 수 있습니다. 대화 제한 기능을 사용하면 제한된 사용자의 ID를 저장합니다.
  • 이용자가 등록한 내용: 학습 기능에 입력한 키워드·응답과 등록한 사용자의 ID를 기능 제공 및 삭제 요청 처리 목적으로 저장합니다.
  • 대화 내용 및 표시 이름: 봇이 설정된 채널에서 호출된 경우 응답을 만들기 위해 호출 문구와 Discord 표시 이름 또는 사용자명을 처리합니다. 현재 구현은 이 대화 내용을 자체 데이터베이스에 저장하지 않지만, AI 응답 생성 시 외부 AI 서비스에 전송합니다.
  • Discord 상호작용 정보: 슬래시 명령과 입력 폼을 처리하는 데 필요한 정보는 Discord를 통해 전달됩니다. 해당 봇 기능에 따라 위 항목 중 일부만 처리합니다.

3. 보유 및 이용 기간

현재 구현은 기능 설정, 호감도, 제한 사용자 ID, 학습 키워드·응답을 봇 실행 환경의 데이터 저장소에 보관하며 자동 만료 기간을 두지 않습니다. 운영자나 해당 봇의 관리자가 삭제하거나 데이터 삭제 요청을 처리할 때까지 보관할 수 있습니다. 대화 문구 자체는 현재 구현에서 봇의 데이터베이스에 보관하지 않지만, 외부 AI 서비스의 처리 및 보유는 해당 서비스의 정책을 따릅니다. 봇별 저장 방식이 다르면 해당 봇의 추가 안내가 우선합니다.

4. 외부 서비스 제공 및 처리

  • Discord: 봇 기능 이용에 필요한 메시지·명령·계정 및 서버 정보를 Discord 플랫폼을 통해 처리합니다. Discord의 개인정보 처리방침이 별도로 적용됩니다.
  • Groq: 현재 AI 응답 기능은 호출 문구와 표시 이름 또는 사용자명을 Groq API에 전송합니다. Groq의 처리 및 보유에는 Groq의 정책이 적용됩니다. AI 기능이 없는 봇에서는 이 전송이 발생하지 않습니다.
  • 봇 호스팅 환경: 봇 데이터는 각 봇을 운영하는 실행 환경에 저장됩니다. 해당 환경의 제공자는 서비스 운영·보안 과정에서 기술 정보를 처리할 수 있으며, 구체적인 제공자와 보유 기준은 봇별 운영 환경에 따라 달라질 수 있습니다.

5. 삭제 및 권리 행사

개인정보 열람·정정·삭제 또는 처리 관련 문의는 위 연락처로 요청할 수 있습니다. 요청 확인에 필요한 최소한의 정보를 확인한 뒤 처리 가능 여부와 결과를 안내합니다. 현재 봇의 학습 문구는 해당 봇의 관리자가 삭제 기능으로 삭제할 수 있습니다. 다른 저장 정보의 삭제가 필요하면 운영자에게 문의해 주세요. 법령상 보관 의무가 있거나 타인의 권리 보호를 위해 필요한 경우 일부 정보는 즉시 삭제되지 않을 수 있습니다.

6. 보호 조치 및 아동의 개인정보

운영자는 데이터 접근을 필요한 범위로 제한하고 합리적인 보호 조치를 적용하기 위해 노력합니다. 다만 인터넷을 통한 전송이나 저장의 완전한 보안을 보장할 수는 없습니다. Discord의 이용 가능 연령과 관련 정책을 준수해야 하며, 아동의 개인정보 처리에 관한 문의나 우려가 있으면 운영자에게 연락해 주세요.

7. 방침 변경

운영자는 처리 방식이나 관련 법령의 변경에 따라 이 방침을 수정할 수 있습니다. 변경 내용과 시행일은 이 페이지에 게시합니다.
